# C++ Date Formatting

A C++ program that formats dates using customizable date format patterns such as `dd/mm/yyyy`, `yyyy/dd/mm`, and `mm-dd-yyyy`.

## Features

- Read a date as a string
- Convert a string date into a `stDate` structure
- Replace specific date format tokens
- Format dates using customizable patterns
- Support multiple date formats
- Use a default date format
- Reuse string manipulation functions

## Concepts Practiced

- Structures
- Strings
- Vectors
- String Manipulation
- `find()`
- `replace()`
- `substr()`
- `erase()`
- `stoi()`
- `to_string()`
- Functions
- Const References
- Default Parameters
- Date Formatting

## Date Format Tokens

The program supports the following format tokens:

| Token | Meaning |
|---|---|
| `dd` | Day |
| `mm` | Month |
| `yyyy` | Year |

dd/mm/yyyy
